### Implementation Overview
1. **Algorithm**: 
   - A single DFS traversal is performed from root `0` downwards.
   - For each node $u$ at depth `depth` with value $nums[u]$, we track the last depth `prev_idx` where $nums[u]$ was previously seen along the current path.
   - The valid ancestor start index for a special path ending at $u$ must be $\ge \max(top\_idx, prev\_idx + 1)$.
   - Because edge weights are positive ($1 \le length_i$), the optimal start index to maximize path length ending at node $u$ is precisely `new_top_idx`.
   - The path length is computed as `dist_so_far - path_dist[new_top_idx]` and node count as `depth - new_top_idx + 1`.
   - Global `max_len` and `min_nodes` are updated across all nodes.
2. **Complexity**:
   - **Time Complexity**: $\mathcal{O}(N)$ where $N \le 50,000$.
   - **Space Complexity**: $\mathcal{O}(N)$ for adjacency list and recursion stack.
3. **Verification**:
   - Passed both public test cases (`[6, 2]` and `[0, 1]`).
   - Stress-tested on maximum constraint trees ($N = 50,000$ deep chains and binary trees).
