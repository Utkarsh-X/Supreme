I have fixed the issue where `ManifestStaticFilesStorage` crashed with `UnboundLocalError` when `max_post_process_passes` was set to `0`.

### Cause
In [`HashedFilesMixin.post_process()`](file:///E:/RofU/Supreme/carb_workspaces/django__django-14493/django/contrib/staticfiles/storage.py#L264), the `substitutions` boolean variable was only initialized inside the `for i in range(self.max_post_process_passes)` loop. When `max_post_process_passes` was set to `0`, `range(0)` was empty and the loop body did not run, leaving `substitutions` unassigned when referenced in `if substitutions:`.

### Fix
- Initialized `substitutions = False` before `for i in range(self.max_post_process_passes):` in [`django/contrib/staticfiles/storage.py`](file:///E:/RofU/Supreme/carb_workspaces/django__django-14493/django/contrib/staticfiles/storage.py#L264).
- Added a regression test `test_post_process_zero_passes` to [`tests/staticfiles_tests/test_storage.py`](file:///E:/RofU/Supreme/carb_workspaces/django__django-14493/tests/staticfiles_tests/test_storage.py#L220).
