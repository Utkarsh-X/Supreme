### Design Overview

**Goal:** Ensure `Engine.render_to_string()` passes `autoescape=self.autoescape` when constructing a `Context` object so that engine-level autoescape settings are respected.

#### Proposed Changes

1. **`django/template/engine.py`**:
   - In `Engine.render_to_string(self, template_name, context=None)`:
     Change `Context(context)` to `Context(context, autoescape=self.autoescape)`.

2. **`tests/template_tests/test_engine.py`**:
   - Add test cases in `RenderToStringTest` to verify:
     - `Engine(autoescape=False).render_to_string(...)` does not auto-escape HTML contents.
     - `Engine(autoescape=True).render_to_string(...)` auto-escapes HTML contents (default behavior).
