### Method Explanation

The problem asks for the minimum number of operations to turn an array $x$ of length $N$ (initially all 0s) into all 1s.
- **Operation 0**: Cost 0. Do nothing.
- **Operation 1** on $[L_i, R_i]$: Cost 1. Sets $x_j = 1$ for $j \in [L_i, R_i]$.
- **Operation 2** on $[L_i, R_i]$: Cost 1. Sets $x_j = 1$ for $j \notin [L_i, R_i]$.

#### Key Mathematical Properties:
1. **Monotonicity & Order Independence**: Operations only transition elements from 0 to 1 and never set elements back to 0. Hence, the order of operations does not matter.
2. **Complement of Op 2**: Performing Op 2 on $[L_i, R_i]$ leaves only elements inside $[L_i, R_i]$ as potential 0s. The intersection of 0-element sets after using a set $S_2$ of Op 2 operations is $\bigcap_{i \in S_2} [L_i, R_i]$.
3. **Helly's Property for 1D Intervals**:
   - If $|S_2| \ge 2$ and there exist two disjoint intervals in $S_2$, their intersection is empty and all elements are covered with cost 2.
   - If all intervals in $S_2$ overlap, their intersection is equal to $[L_a, R_b]$ where $a = \arg\max_{i \in S_2} L_i$ and $b = \arg\min_{i \in S_2} R_i$. Thus, $|S_2|$ never needs to exceed 2 in any optimal solution.
4. **Cost Upper Bound**: The optimal total cost $K$ is at most 3 whenever $M \ge 3$. Specifically:
   - **Cost 1**: Possible if and only if there is an interval $[1, N]$ for Operation 1.
   - **Cost 2**: Possible if:
     - Two Operation 1 intervals cover $[1, N]$.
     - Two Operation 2 intervals are disjoint ($\min R_i < \max L_i$).
     - One Operation 2 interval $[L_i, R_i]$ is covered by an Operation 1 interval $[L_j, R_j]$ ($L_j \le L_i \le R_i \le R_j$).
   - **Cost 3**: Achievable for any $M \ge 3$ by picking $a = \arg\max L_i$, $b = \arg\min R_i$, and any distinct $c \notin \{a, b\}$ with $\text{op}_a = 2, \text{op}_b = 2, \text{op}_c = 1$.
   - **Impossible (-1)**: Only when $M < 3$ and costs 1 and 2 cannot be achieved.

### Complexity
- **Time Complexity**: $\mathcal{O}(N + M)$ total time.
- **Space Complexity**: $\mathcal{O}(N + M)$ total memory.
