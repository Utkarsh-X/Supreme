I have resolved the issue where index entries for `py:method` directives with the `:property:` option incorrectly included parentheses `()`.

### Root Cause
In [sphinx/domains/python.py](file:///E:/RofU/Supreme/carb_workspaces/sphinx-doc__sphinx-9698/sphinx/domains/python.py#L784-L804), `PyMethod.get_index_text` included parentheses `()` for method entries even when the `:property:` option was set (e.g. `_('%s() (%s property)')`). Since properties are accessed as attributes rather than invoked like functions/methods, they should not have parentheses `()` in their index entries.

### Solution
1. Updated `PyMethod.get_index_text` in [sphinx/domains/python.py](file:///E:/RofU/Supreme/carb_workspaces/sphinx-doc__sphinx-9698/sphinx/domains/python.py#L784-L804) so that when `'property'` is in `self.options`, the index entry string is rendered without `()` (matching the behavior of `PyProperty.get_index_text`).
2. Updated unit test assertions in [tests/test_domain_py.py](file:///E:/RofU/Supreme/carb_workspaces/sphinx-doc__sphinx-9698/tests/test_domain_py.py#L756-L764) to verify property index entries registered via `py:method` do not contain parentheses.
