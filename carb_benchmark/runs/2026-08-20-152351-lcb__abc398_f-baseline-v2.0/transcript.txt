### Method Explanation
To construct the shortest palindrome having $S$ as its prefix, we need to find the longest palindromic suffix of $S$. If $S = A + P$, where $P$ is the longest palindromic suffix of $S$, then appending $A^R$ (the reverse of $A$) to $S$ yields $A + P + A^R$, which is a palindrome of minimal total length.

We compute the length of $P$ using the Knuth-Morris-Pratt (KMP) prefix function algorithm:
1. Construct string $T = S^R + \text{'\#'} + S$.
2. Compute the KMP $\pi$ table (prefix function array) for $T$.
3. The value $\pi[|T|-1]$ gives the length of the longest proper prefix of $T$ that is also a suffix of $T$. Because $T = S^R + \text{'\#'} + S$, this matching length represents the length of the longest palindromic suffix of $S$.
4. The remaining prefix $A = S[0 : |S| - \text{pal\_len}]$ is reversed and appended to $S$.
