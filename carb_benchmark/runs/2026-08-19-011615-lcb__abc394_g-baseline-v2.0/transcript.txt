### Summary of Approach

1. **Problem Formulation & Reduction**:
   - For a journey starting at building $(A_i, B_i)$ floor $Y_i$ and ending at building $(C_i, D_i)$ floor $Z_i$, Takahashi can freely use walkways at floor $X$ between adjacent buildings if both have height $\ge X$.
   - The maximum floor $X$ at which building $(A_i, B_i)$ and building $(C_i, D_i)$ are in the same connected component of buildings of height $\ge X$ is $L(s, t)$ (the maximum bottleneck path capacity between cell $s$ and cell $t$).
   - If Takahashi needs to travel between $s$ and $t$, the minimum stairs required is $Y_i + Z_i - 2 \cdot \min(Y_i, Z_i, L(s, t))$.

2. **Graph Construction & Kruskal Reconstruction Tree**:
   - We construct a grid graph with $V = H \times W$ nodes and $E < 2 HW$ edges. Each edge $(u, v)$ has weight $\min(F_u, F_v)$.
   - Sorting all edges in descending order of weight, we build a **Kruskal Reconstruction Tree** (Reachability Tree) using Disjoint Set Union (DSU).
   - In this tree, $L(s, t)$ is precisely the value of the Lowest Common Ancestor (LCA) node of leaf $s$ and leaf $t$.

3. **Optimized LCA & Fast Queries**:
   - The Kruskal tree has $2V - 1$ nodes, constructed top-down without recursion.
   - We use Binary Lifting (`up` table of height $\log_2(2V) = 19$) with bitwise jump optimizations to process each of the $Q = 2 \times 10^5$ LCA queries in $O(\log V)$ time.
