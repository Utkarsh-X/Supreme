### Key Insights

1. **Disjointness Graph Properties**:
   An edge exists between vertices $i$ and $j$ if and only if interval $i$ is strictly to the left of interval $j$ ($R_i < L_j$) or interval $j$ is strictly to the left of interval $i$ ($R_j < L_i$).
   
2. **Path Length Bound**:
   Any shortest path between $s$ and $t$ ($s \neq t$) requires **at most 3 hops**. In fact, any path in $G$ falls into one of 5 canonical candidates:
   - **1-hop (Direct edge)**: $s \to t$, valid if $R_s < L_t$ or $R_t < L_s$.
   - **2-hop via Left**: $s \to u \to t$, where $R_u < \min(L_s, L_t)$.
   - **2-hop via Right**: $s \to u \to t$, where $L_u > \max(R_s, R_t)$.
   - **3-hop (Left-Right)**: $s \to a \to c \to t$, where $R_a < L_s$ and $L_c > R_t$.
   - **3-hop (Right-Left)**: $s \to a \to c \to t$, where $L_a > R_s$ and $R_c < L_t$.

3. **$O(1)$ Per-Query Evaluation**:
   By precomputing prefix minimum weight arrays for left endpoints (`min_left[x] = min { W_a | R_a < x }`) and suffix minimum weight arrays for right endpoints (`min_right[y] = min { W_c | L_c > y }`) in $O(N)$ time, each of the candidate path structures can be queried in $O(1)$ time.
