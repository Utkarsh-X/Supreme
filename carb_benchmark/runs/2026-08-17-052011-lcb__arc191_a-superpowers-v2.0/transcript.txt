### Summary of Approach
1. **Mathematical Insight**:
   - The operation applies $M$ replacements in order. Since each operation $k \in \{0, \dots, M-1\}$ must target some index $i \in \{0, \dots, N-1\}$, the last operation $k = M-1$ (which places digit $v = T[M-1]$) MUST be assigned to some position $j \in \{0, \dots, N-1\}$.
   - All other operations $k \in \{0, \dots, M-2\}$ supply a multiset $A$ of $M-1$ digits. Each digit in $A$ can be used at most once across all indices $i \neq j$.
2. **Finding the Optimal Target Position $j$**:
   - We first simulate the full greedy replacement on $S$ using digits from $A$ to obtain $S_{\text{full\_greedy}}$.
   - We determine the optimal index $j_{\text{opt}}$ to receive $v = T[M-1]$ using the following rule:
     1. Pick the first index $i$ where $v > S_{\text{full\_greedy}}[i]$ (if any exists).
     2. Else, pick the first index $i$ where $v == S_{\text{full\_greedy}}[i]$ (if any exists).
     3. Else, pick $j_{\text{opt}} = N-1$.
3. **Constructing the Result**:
   - We perform the greedy replacement pass on $S$ with pool $A$, fixing position $j_{\text{opt}}$ to $v = T[M-1]$.
   - This runs in $O(N + M)$ time and $O(N + M)$ space.
