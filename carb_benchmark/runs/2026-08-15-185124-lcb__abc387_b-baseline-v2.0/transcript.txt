### Solution Overview
The program reads an integer $X$ from standard input and computes the sum of all elements in the $9 \times 9$ multiplication table except those equal to $X$:
$$\text{Sum} = \sum_{i=1}^{9} \sum_{j=1}^{9} (i \times j \quad \text{if } i \times j \neq X \text{ else } 0)$$
