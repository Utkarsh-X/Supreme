\subsection{Context-Growth Dynamics and Multi-Turn Token Economics}
As illustrated in Figure~\ref{fig:token_sinks}, multi-turn agent execution exhibits distinctive context characteristics:
\begin{enumerate}
    \item \textbf{Prior History Accounts for the Majority of Context (90.5\%)}: Across all three paradigms, re-reading prior conversational turns accounts for over 90\% of cumulative input tokens. Initial prompt length optimizations (e.g., saving $\approx 3,600$ tokens in initial headers) are quickly eclipsed by the volume of accumulated dialogue and tool outputs.
    \item \textbf{On-Demand Skill Context Accumulation}: Loading procedural skill documents on-demand resulted in Superpowers accumulating \textbf{411,332,767 cache read tokens} (\texttt{cached\_content\_token\_count}), compared to 322,810,412 for Supreme and 295,918,105 for Baseline \cite{google2026gemini36}. Inserting extensive documentation into the active turn history increases context volume on subsequent turns, showing that dynamic retrieval is associated with additional accumulated context volume across subsequent turns.
    \item \textbf{Terminal Stdout Sinks}: Unclipped shell outputs (\texttt{make} logs, compiler warnings) represented 67.8\% of tool payload tokens, demonstrating that automated output clipping is essential to prevent context dilution regardless of prompt architecture.
\end{enumerate}

Across all 89 tasks, evaluation expenditure and outcomes present a three-layer economic portrait. In absolute terms, Baseline incurred the lowest total effective paid cost (\$27.33), followed by Superpowers (\$29.35) and Supreme (\$29.80). At the per-execution level, Baseline again recorded the lowest cost per attempted task (\$0.307), followed by Superpowers (\$0.330) and Supreme (\$0.335). These absolute and per-attempt cost advantages coincide with Baseline's lower token footprint (31.22M total billed tokens vs.\ 34.52M for Supreme), but also with its lower task completion (55/89 vs.\ 61/89).

Cost per successful task is a composite outcome-efficiency measure combining total evaluation expenditure with the number of tasks successfully completed; it is not an independent cost measurement. On this dimension, Supreme achieved the lowest effective paid cost per successful task (\$0.489), approximately 3.4\% below Superpowers (\$0.506), while completing three additional tasks (61 vs.\ 58). Baseline achieved \$0.497. The cost-per-successful-task ranking is unchanged under both list-price and effective-paid pricing as detailed in Table~\ref{tab:cost_economics}, confirming that this efficiency relationship is not an artifact of the specific pricing rates applied.

On the Hard task subset ($N=30$), the cost-per-successful-task ranking reverses: Baseline achieved the lowest cost per successful Hard task (\$0.645), followed by Supreme (\$0.680) and Superpowers (\$0.730). Supreme simultaneously achieved the highest Hard-task completion rate (66.7\% [20/30] vs.\ 56.7\% [17/30] for Baseline and 53.3\% [16/30] for Superpowers). This represents a genuine trade-off: superior Hard-task coverage at moderately higher cost per successful Hard solve compared to Baseline.

\subsection{Architectural Implications for Agent Systems}
Our findings offer three practical considerations for autonomous coding systems:

\noindent\textbf{Invariant Principles in Static Headers}: Placing invariant engineering axioms directly in static headers avoids mid-turn documentation file retrieval while maintaining consistent behavioral constraints across turns.

\noindent\textbf{Loop Termination Heuristics}: Agent frameworks with flexible procedural guidance require explicit iteration thresholds and hypothesis-checking gates to prevent open-ended exploratory scripting on combinatorial search problems.

\noindent\textbf{Targeted Line Edits}: Encouraging surgical diff tools (\texttt{replace\_file\_content}) over whole-file rewrites correlates with reduced collateral modifications in multi-file codebases.

\subsection{Threats to Validity and Limitations}

\noindent\textbf{Single Foundation Model}: All evaluations used Gemini 3.6 Flash High. Model-specific reasoning, context handling, and tool policies may interact with prompt architecture; findings should not be assumed to generalize universally across model families without multi-model replication.

\noindent\textbf{Single Run per Task}: Each task was evaluated with one run per configuration at $\tau=0.0$ (267 container runs, $\approx 50$ compute hours). While $\tau=0.0$ minimizes sampling variance, multi-seed replication is necessary to measure run-to-run stability.

\noindent\textbf{Coupled Structure and Content}: Supreme and Superpowers differ in both structure (static vs.\ dynamic) and instructional content (constitutional axioms vs.\ TDD/debugging workflows). Controlled ablations isolating delivery mechanism from content remain an important direction for future research.

\noindent\textbf{Prompt Freezing}: The Supreme constitutional prompt was authored prior to benchmark execution and frozen; no prompt adjustments were made based on benchmark task failures.


\section{Conclusion}
\label{sec:conclusion}
In this work, we compared the behavior of substantially different agent-guidance configurations --- constitutional static grounding and dynamic progressive skill loading --- under a shared foundation model, evaluation harness, and benchmark corpus across all 89 tasks of Terminal-Bench 2.1 (267 container evaluations). Constitutional static grounding achieved a favorable position across task completion (61/89, 68.5\%), aggregate wall-clock time (15.15\,h, 17.2\% lower than Superpowers), and effective paid cost per successful task (\$0.489, approximately 3.4\% below Superpowers), with a directional Hard-task advantage (66.7\% vs.\ 53.3\%; McNemar $p = 0.22$). While aggregate pass rates across the full 89-task corpus are not statistically distinguishable under paired McNemar tests ($p > 0.05$), and the configurations differ in both guidance structure and instructional content, the evaluation reveals substantial differences in execution dynamics, token economics, and behavioral trajectories observed consistently across the analyzed execution traces and evaluation cohorts. Complete execution transcripts, harness configurations, and cryptographic verification ledgers are made available for independent replication.
